# LLess

Single-user, local-first statistical decision notebook. Users record scenarios before outcomes are known, explore distributions, and preserve immutable versions with frozen branch context. Never recommend or rank a choice. All omitted inputs, approximations and assumptions remain visible. Questions are bounded, resumable and skippable. Primary scene: focused desktop analysis, with usable mobile review.

The MVP uses FastAPI, an encrypted SQLite payload store and a dependency-free browser client. Offline questioning and retrieval are deterministic fallbacks, clearly disclosed. External model access is optional, never required for calculations.
